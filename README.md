# Hosted Metrics Dashboard Data Simulation

This Python script simulates custom business metrics data that could be ingested by a hosted metrics dashboard. It generates time-series data for user registrations, orders, revenue, and customer satisfaction, illustrating the type of data a startup might track.

## Language

`python`

## How to Run

Run this script using Python: `python metrics_dashboard_sim.py`
